## 이 묶음을 읽는 분께

세 문서가 공통으로 지키는 원칙이 있습니다.

**첫째, 사람 검수 점수는 어디에도 없습니다.** `scripts/build_review_sheet.py` 에
검수자 항목이 정의되어 있으나 채점된 정본이 없습니다. 심미성·설득력 같은 판단이
필요한 자리에는 **관리자의 육안 판정 문구를 원문 그대로** 인용했고, 점수를 만들어
넣지 않았습니다.

**둘째, 미검증 항목을 숨기지 않았습니다.** 배포 환경(AWS L40S)에서 측정하지 못한
것이 여럿 있습니다. 대표적으로 건당 처리 시간, SGLang 두 서버의 호스트 RAM 합산
피크, 누끼의 GPU 전환 동작입니다. 전부 "미검증" 으로 표시했습니다.

**셋째, 우리 산출물이 기준에 못 미치는 것도 그대로 적었습니다.** 13차에서 다양성
기준을 바로잡은 결과 60건 평가가 평균 집합 일치도 미달로 바뀌었습니다. 통과시키려
기준을 조정하지 않았습니다.

## 제출 이후 확인된 사실 (2026-09-23)

본문 세 문서는 2026-09-22 시점 기록이라 **고치지 않습니다.** 다만 그 뒤에 한 항목이
뒤집혔으므로 여기에 적어 둡니다.

`01-ai-evaluation-report.md` 3-4절은 13차 변경으로 **생성컷 사용이 0장에서 5장이
되었다**고 적고 있습니다. 그 실행에서는 사실이었습니다. 그러나 이후 다른 두 품목
(합죽선 매화선, 청자 분청 찻잔)으로 돌려 보니 **생성컷 5장이 전부 다시 버려졌습니다.**
13차 변경은 `usage_scene` 자리를 만드는 데까지만 효과가 있었고, `gallery` 블록의
`photo_ids` 를 모델이 규약과 다르게 채우는 문제가 남아 있었습니다.

2026-09-23 에 갤러리 사진을 코드가 확정하도록 고쳐서 미사용 생성컷이 5장에서 1장으로
줄었습니다. 같은 수정으로 **렌더된 PNG 와 `react_document` 의 갤러리 사진이 달랐던
결함**도 함께 닫혔습니다.

| 항목 | 값 |
