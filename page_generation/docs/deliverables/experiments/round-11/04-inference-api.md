## 1. 변경 없음

이 차수는 모델 호출 계약(추론 API)을 건드리지 않았다. 직전 차수 계약을 그대로 유지한다.

컷아웃 추출 로직과 충실도 검증 게이트는 상세페이지 생성 파이프라인 내부에서 로컬 CPU 연산으로 동작하는 컴퓨터 비전(CV) 전처리 및 사후 품질 검증 단계다. 따라서 외부 LLM 추론 모델(프롬프트 구성, 시스템/유저 메시지 구조, JSON 스키마)이나 이미지 생성 모델(Flux 파라미터, 엔드포인트)의 호출 규격에는 일체의 변경이 발생하지 않았다.

직전 10차에서 정립된 다음 추론 API 계약이 100% 동일하게 유지된다:
- `SECTION_PLAN_PROMPT`의 4개 후보 레이아웃 원형 주입 및 근거 기반 선택 계약 유지
- 모델 응답 `PagePlanDto` 배열 스키마 무변경 유지
- `configured_image_model` 및 provider 분기(`MlxServeImageClient` 등) 설정 무변경 유지

## 2. 호출 횟수 및 런타임 소요 시간 분석

### 1) 호출 횟수
60건 전수에 대해 텍스트 추론 및 Flux 이미지 생성을 케이스당 5장(총 300장 생성)씩 100% 정상 수행했다.

### 2) 60건 2차 실행 소요 시간 변화
- **60건 1차 실행 (`full60-20260910-204433`)**: 총 3시간 52분 소요 (건당 평균 227초).
- **60건 2차 실행 (`full60-v2-20260911-110752`)**: 총 4시간 13분 소요 (건당 평균 253초).
- **건당 +26초 지연 발생 원인**: 외부 모델 추론 지연이 아니라, 컷아웃 추출기가 즉시 포기(폴백)하지 않고 실제 배경 분리를 시도한 케이스가 9건에서 24건으로 증가함에 따라 고해상도 이미지의 연결성 분석, 플러드필, 알파 마스크 생성 등 CPU 전처리 연산 시간이 추가된 결과다.

### 3) 추출기 되돌림 이후 상태
커밋 `162863d`로 추출기 로직이 10차 시점(`corner_uniformity_tolerance=24.0`, 51건 폴백)으로 완전히 원복되었으므로, 실제 런타임 처리 시간 역시 1차 실행 기준인 건당 약 227초 수준으로 복귀했다.
