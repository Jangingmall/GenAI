## 사건 1 — 코드 선택으로도 한 쌍이 완전히 충돌

### 증상

코드가 한 원형과 순서를 정해 모델의 구조 선택을 제한했지만, 서로 다른 상품 두 건이 같은 블록 집합을 받았다.

### 증거

평균 Jaccard는 72.4%, 유효 공통 블록은 4종, 완전 일치 쌍은 1쌍, 고유 시퀀스는 5종/6건, 최빈 반복은 2회였다. 지정 순서 보존은 6/6건이었고, 근거 부족으로 생략된 건은 1건이었다.

### 원인

이미지 SHA-256 하나로 카탈로그 원형 하나를 고르는 방식은 상품의 `when`·`avoid_when` 조건을 평가하지 않았다. 서로 다른 상품이 같은 원형으로 해시될 수 있었다.

### 조치

코드가 page_plan의 원형과 순서를 결정하고 모델은 카피만 쓰도록 했다. 근거 없는 블록은 생략해 지어낸 내용을 막았다.

### 재발 방지

후속 기록에서 해시 하나의 단일 선택과 상품 근거 기반 후보 선택을 분리해 기록했다. 구조 성공 판정에는 충돌 쌍과 유효 공통 블록을 포함했다.

## 이월 중인 결함

카탈로그 `when`·`avoid_when` 미사용과 해시 충돌이 이월됐다. 구 기준의 평균 60%·전체 공통 4종·완전 일치 0쌍은 미달 상태였고, 사람 검수 점수도 없었다.
