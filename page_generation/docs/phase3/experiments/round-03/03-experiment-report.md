## 문제

Round 02는 최빈 반복을 줄였지만 모든 블록이 후보로 남아 공통 집합이 크게 겹쳤다. 제작 과정 데이터가 없는 상품에 `statement`가 외형 묘사로 채워질 가능성도 있었다.

## 가설

블록별 선택·생략 조건과 `statement`의 제작 과정 데이터 게이트를 넣으면 근거 없는 블록이 빠지고 집합 중복이 줄어들 것이라고 가정했다.

## 실험 설계

`build_analysis_prompt`에 블록별 조건을 추가하고, `statement`는 creator-provided `howMade`가 있을 때만 허용했다. 입력 데이터, 모델, 이미지 재생성은 고정했다.

## 실행 명령

- 파일럿 생성기는 `scripts/run_eval_pilot.py`였다. 저장된 `run_index.json`에는 전체 CLI 인자가 보존되어 있지 않다.
- 구성 측정: `.venv/bin/python scripts/check_plan_diversity.py generated/evaluation/pilot-20260910-115722`
- 컷아웃 측정: `.venv/bin/python scripts/check_cutout_fidelity.py generated/evaluation/pilot-20260910-115722 --role hero`

## 측정 수치

유효 공통 블록은 `hero`와 `closing`을 제외한 종수다. 당시 구 기준은 평균 Jaccard `<=60%`, 전체 공통 블록 `<=4종`, 완전 일치 `0쌍`이었다.

| 지표 | 실측값 |
|---|---:|
| 평균 Jaccard | 78.3% |
| 유효 공통 블록 | 4종 |
| 완전 일치 쌍 | 2쌍 |
| 고유 시퀀스 | 4종/6건 |
| 최빈 반복 | 2회 |
| 길이 분포 | 8블록 5건, 9블록 1건 |
| 파일럿 성공 | 6/6 |
| 컷아웃 게이트 | OK 6건, 부분 손실 0, 심각 손실 0 |
| 소요 시간 | 27.3분 |

## 판정

구 기준 `FAIL`이었다. 유효 공통 블록은 4종까지 줄었지만, 당시 전체 공통 기준은 구조 고정 블록도 포함했고 평균 78.3%와 완전 일치 2쌍도 기준을 넘었다.

## 그 차수가 입증하거나 반증한 것

선택·생략 조건은 Round 02의 93.3%·유효 공통 6종·완전 일치 10쌍을 78.3%·4종·2쌍으로 낮췄다. 근거 없는 블록을 생략하면 수렴이 줄어든다는 가설은 입증됐다. 그러나 원형 선택 없이 게이트를 모두 만족한다는 가설은 반증됐다.

## 남은 한계

상품별 큰 구조를 선택하는 원형 계약이 없었다. 6건 파일럿이며 사람 검수 점수는 없었다.
