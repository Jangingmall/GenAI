## 1. 개요: 채택과 되돌림의 분리

Round 11은 60건 1차 평가에서 드러난 **85% 컷아웃 미수행(폴백)** 문제를 해결하기 위해 컷아웃 검증 게이트 보강과 추출기 수정을 동시에 추진한 차수다.

최종적으로 **게이트 보강, 독립 정답 집합, 회귀 감사 도구는 채택**되어 저장소에 유지되었고, **추출기 로직 수정은 관리자 육안 확인 판단에 의해 반려되어 커밋 `162863d`로 완전히 되돌려졌다.** 실패한 시도와 채택된 자산을 명확히 분리하여 기록한다.

## 2. 채택된 변경 사항 (Commit `696dd15`)

파이프라인 산출물 이미지를 변경하지 않고, 컷아웃의 상태와 품질을 정확히 측정·감사하기 위한 인프라 변경은 전건 채택되었다.

### 1) 컷아웃 충실도 검증 게이트 보강
- **파일**: `scripts/check_cutout_fidelity.py`
- **주요 변경 내용**:
  - **'손실(Loss)'과 '미수행(Fallback)'의 개념 분리**: 기존 게이트가 원본 그대로 출력된 폴백 이미지를 산출물=원본으로 보아 '보존율 100% OK'로 오판하던 구조를 수정하여, `fidelity_status`가 `FALLBACK`인 케이스를 `UNATTEMPTED`로 분리 집계했다.
  - **배경 잔존(Residual Background) 탐지 추가**: 제품 내부 루프나 폐곡선에 배경이 남는 결함을 포착하기 위해 배경 잔존율을 계측하고, 임계값 1.0%를 적용했다 (데이터 실측 근거: 최악 결함 `cma-109609` 19.22% vs 정상 제품 `cma-168479` 0.62%).
  - **성긴 제품(Sparse Product) 실루엣 밀도 보정**: 얇은 링이나 목걸이 등 구멍이 큰 제품이 바운딩 박스 대비 면적이 작아 손실로 오판되는 현상을 방지하기 위해 실루엣 밀도 30.0% 예외 기준을 신설했다 (실측 근거: 정상 고리형 장신구 27.77% vs 다음 값 45.35%, 15.35%p 분리 구간).
  - **실행 요약 지표 개선**: 실행 결과 요약에 총 실행 케이스 중 실제 컷아웃이 수행된 비율(`share of run actually cut`)을 의무 출력하도록 했다.

### 2) 독립 정답 데이터셋 구축
- **파일**: `docs/phase4/evaluation/cutout-ground-truth.md`, `docs/phase4/evaluation/cutout-baseline-metrics.json`
- **주요 내용**:
  - 60건 전체 냉동 산출물에 대한 정밀 시각 검수를 거쳐 독립적인 컷아웃 정답 레이블을 구축했다.
  - 분류 결과: 침식 partial 4건(`cma-165266`, `cma-165267`, `cma-165271`, `cma-122443`), 폐곡선 잔존 2건(`cma-159023`, `cma-131719`), 테두리 잔존 52건, 정상 통과 2건.

### 3) 회귀 감사 도구 구축 및 불변 데이터 바인딩
- **파일**: `scripts/audit_cutout_truth.py`, `scripts/compare_cutout_regression.py`
- **주요 내용**:
  - **동적 코드 의존성 제거**: 기존에 파이썬 추출기 코드를 라이브로 재실행하여 정답을 판정하던 구조적 결함을 제거하고, 디스크에 고정된 불변 산출물(`photos/01-hero.*`, `result_summary.json`)의 메타데이터와 픽셀 데이터만을 읽도록 전면 리팩토링했다.
  - **케이스별 전이 추적**: 수정 전후의 산출물을 대조하여 `FALLBACK -> VERIFIED`, `VERIFIED -> VERIFIED`, 그리고 특히 개별 케이스의 품질이 악화되는 역전이(regression)를 낱낱이 보고하는 비교 도구를 신설했다.

### 4) 신규 테스트 스위트
- **파일**: `tests/test_cutout_truth.py`, `tests/test_cutout_regression.py`, `tests/test_eval_scripts.py`
- **내용**: 게이트 판정 규칙, 임계값 구간 검증, 독립 정답 집합 일치성 및 회귀 비교 로직을 검증하는 테스트 스위트를 추가했다.

## 3. 반려 및 되돌려진 변경 사항 (Commit `162863d`)

### 1) 추출기 1차 수정 시도 (반려)
- **수정 내용**: 모서리 4점 평균 단일 색상 가정을 16픽셀 격자 공간 배경 모델로 교체하고 `background_tolerance`를 28.0에서 36.0으로 완화.
- **결과**: 폴백 수는 51건에서 3건으로 급감하고 컷아웃 수행은 9건에서 57건으로 늘었으나, 제품을 깎아먹는 침식(HIGH erosion)이 4건에서 35건으로 폭증했다 (`cma-142759` 447,023px, `cma-149146` 447,265px 손실).
- **판정**: 57건을 시도하고도 깨끗한 컷아웃은 12건에 불과하여 반려되었다.

### 2) 추출기 2차 수정 시도 (수행 24건, 폴백 36건)
- **수정 내용**: 분리가 불확실하거나 위험한 이미지는 폴백으로 넘기고 안전한 영역만 컷아웃하도록 휴리스틱 조정.
- **결과**: 60건 중 24건 컷아웃 수행, 36건 폴백. 위험한 33건을 폴백으로 방어하면서도 1차와 동일한 12건의 깨끗한 컷아웃을 확보했다.

### 3) 최종 결정: 육안 판정에 의한 전면 되돌림
- **파일**: `src/detail_page_ai/source_photos.py`, `tests/test_source_photos.py`
- **되돌림 사유**: 60건 2차 전체 실행 산출물에 대해 관리자가 전후 비교 갤러리를 육안 확인한 뒤 **"이전이 나은 것 같다"**고 판단했다. 어떤 시각적 속성 때문인지는 기록되지 않았으며, 자동 지표의 개선(깨끗한 컷아웃 3->13건, 역전이 0건)에도 불구하고 관리자의 육안 판단이 우선 적용되었다.
- **조치**: 커밋 `162863d`를 통해 `source_photos.py`와 `tests/test_source_photos.py`의 추출기 코드를 10차 시점 상태로 완전히 원복했다.
