## 1. 문제
Round 08은 새 기준을 적용했음에도 평균 Jaccard 66.01%(임계값 64.52%), 완전 일치 2쌍(허용치 1쌍)으로 미달했다. 이미지 해시 하나로 25종 중 1개 원형을 직접 결정하는 방식은 카탈로그에 공들여 정의된 `when`과 `avoid_when` 조건을 전혀 읽지 않아, 상이한 상품이 우연히 같은 원형에 당첨되는 충돌을 막을 수 없었다.

## 2. 가설

  - 이미지 재생성: Flux 9B 모델을 가동하여 텍스트 및 이미지 완전 생성.
- **통제 요소**:
