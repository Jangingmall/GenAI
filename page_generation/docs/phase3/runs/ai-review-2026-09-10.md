# AI 참고 검수 결과와 미수정 결함 기록

- **검수일**: 2026-09-10
- **대상**: `generated/evaluation/pilot-20260909-224737`의 6건
- **목적**: 이번 검수 사이클의 결정과 미수정 결함을 기록하고 배포 판단의 근거를 남김

이 문서의 AI 점수는 사람 검수를 대신하지 않는 참고치다. 사람 검수 2인의 공식 점수나
합의 점수로 사용하지 않는다.

## 1. 검수 결정

### 1.1 사람 검수 생략

이번 사이클에서는 PM 2인의 사람 검수를 수행하지 않기로 했다. 따라서 사실성·명료성·
상품성·시각품질 4축의 **공식 점수는 존재하지 않는다**. `docs/phase2/metrics-definition.md`
는 개정하지 않았고, 그 문서의 "미검수는 정답으로 사용하지 않는다"는 원칙을 유지한다.

### 1.2 AI 검수는 참고치

서로 다른 모델 2개가 같은 6건을 독립적으로 채점했다. 원본은
[`ai_review_codex.json`](../../../generated/evaluation/pilot-20260909-224737/ai_review_codex.json)과
[`ai_review_agy.json`](../../../generated/evaluation/pilot-20260909-224737/ai_review_agy.json)이며,
각 점수의 축 순서는 **사실성·명료성·상품성·시각품질**이다. 아래 표의 모든 값은 공식
점수가 아닌 AI 참고치다.

| case | Codex (GPT-5) 참고치 | Agy (gemini-2.5-pro) 참고치 |
|---|---:|---:|
| `analysis-cma-102980` textile | 4·4·4·4 | 5·5·4·4 |
| `analysis-cma-101636` box | 4·4·4·4 | 5·5·5·4 |
| `analysis-cma-114971` metalware | 4·4·4·4 | 5·5·4·4 |
| `analysis-cma-122443` ceramic | 4·4·4·4 | 5·4·4·2 |
| `analysis-cma-109609` jewelry | 4·4·4·4 | 4·3·4·5 |
| `analysis-cma-110793` furniture | 3·4·3·4 | 4·3·2·2 |

관찰 사항은 다음과 같다.

- Codex는 6건 중 5건을 4·4·4·4로 채점해 변별력이 낮았다.
- 두 모델의 차이가 2점인 축은 ceramic과 furniture의 시각품질이다(Codex 4, Agy 2).
- 사람 검수를 수행했다면 이 편차와 각 모델의 근거를 합의 대상으로 삼았겠지만, 이번
  사이클에서는 그 절차가 없었다.

## 2. 미수정 결함

### 2.1 결함 A — 생성 참고 컷의 `참고용` 표시 누락

**상태: 배포 차단 조건 5, 미수정.** 이 결함은 Codex가 6건 전부에 제기했고 코드와
파일럿 산출물로 확인한 사실이다.

#### 증거

- 각 `generated/evaluation/pilot-20260909-224737/*/react_document.json`에 대해
  `grep -c '참고용'`을 실행한 결과가 6건 모두 `0`이었다.
- 각 `result_summary.json`에는 `generated_scene` 1개와 `generated_view` 4개의 자산 항목이 있고, 이 항목들의
  `product_generated` 값은 모두 `true`다.
- [`src/detail_page_ai/html_renderer.py`](../../../src/detail_page_ai/html_renderer.py)의
  513~518행은 생성 자산을 URI 목록에 포함할지 `asset_mode`로 판단할 뿐, 화면에
  `참고용` 라벨을 그리지 않는다.

    if not photo.product_generated
    or (photo.photo_id == "lifestyle" and photo.asset_mode == "generated_scene")
    or (
        photo.photo_id in {"detail-02", "detail-03", "detail-04", "detail-05"}
        and photo.asset_mode == "generated_view"
    )

즉 데이터 계약에는 생성 자산과 `generated_scene`/`generated_view`가 남아 있지만, 고객이
보는 최종 렌더에는 생성 참고 컷임을 알려 주는 표시가 없다. 이는 README가 생성 결과를
참고용 이미지로 표시하고 FE/BE DTO에 생성형 자산임을 표시한다고 선언한 내용과 실제
렌더 경로가 어긋나는 것이다. 평균 점수와 무관하게 배포 불가 조건이다.

#### 이번 사이클의 결정과 수정 방향

이번 사이클에서는 코드를 수정하지 않기로 했다. 후속 수정 방향만 기록한다.

1. `react_document_builder`가 생성 자산에 캡션 또는 라벨 메타데이터를 내보낸다.
2. `html_renderer`가 `generated_scene`와 `generated_view`를 고객 화면에 각각
   `AI 생성 활용 장면(참고용)` 또는 `AI 생성 디테일(참고용)`으로 렌더한다.
3. 6건의 JSON 라벨 존재 검증과 최종 PNG의 시각 표시 검증을 배포 gate에 추가한다.

### 2.2 결함 B — furniture 1건의 형태 왜곡 의심

**상태: 미검증. 사실로 단정하지 않는다.** Agy는
`analysis-cma-110793`(furniture)에 대해 원본 막대 끝의 인면 조각 장식이 생성
활용 장면에서 다른 형태로 보이고 막대 배치가 물리적으로 부자연스럽다는 이유로,
배포 차단 조건 3번에 해당할 수 있다고 제기했다. 그러나 사람 검수를 수행하지 않았으므로
이 관찰을 확정 결함이나 공식 gate 결과로 기록하지 않는다. 사람의 원본·생성 컷 대조와
합의가 완료되기 전까지 미검증 상태로 남긴다.

## 3. 배포 판단

- AI 점수는 참고치일 뿐이며 이번 사이클에는 4축 공식 점수가 없다.
- 결함 A의 생성 참고 컷 표시 누락은 6건 모두에서 확인됐고, 배포 차단 조건 5가
  미해결이므로 배포 불가 상태다.
- 결함 B는 사람 검수 전까지 미검증으로 유지한다.
- 이 문서 작성은 결함 A/B를 수정하거나 사람 검수·파일럿을 대체하지 않는다.
