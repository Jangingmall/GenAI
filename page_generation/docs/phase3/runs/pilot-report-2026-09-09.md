## 4. 발견된 중대 결함: Hero 컷아웃 소실 (Cutout Erosion)

자동 구조 gate는 전부 통과했으나, **Hero 컷아웃(`01-hero.*`) 생성 과정에서 원본 제품의 실루엣과 본체가 심각하게 삭제되는 결함 2건**이 발견되었습니다.

### 4.1 결함 현황 및 보존율 실측
`scripts/check_cutout_fidelity.py` 도구를 통해 원본 입력 이미지와 산출물 Hero 사진의 비배경(잉크) 픽셀 비율을 비교한 결과는 다음과 같습니다:

```text
| 카테고리 | case_id | photo 역할 | 원본 잉크 비율 | 산출 잉크 비율 | 보존율 | 판정 |
|---|---|---|---|---|---|---|
| textile | analysis-cma-102980 | hero | 1.0000 (100.0%) | 0.2624 (26.2%) | 0.2624 (26.2%) | 부분 손실 |
| box | analysis-cma-101636 | hero | 1.0000 (100.0%) | 1.0000 (100.0%) | 1.0000 (100.0%) | OK |
| metalware | analysis-cma-114971 | hero | 0.9964 (99.6%) | 0.9964 (99.6%) | 1.0000 (100.0%) | OK |
| ceramic | analysis-cma-122443 | hero | 0.9994 (99.9%) | 0.0324 (3.2%) | 0.0324 (3.2%) | 심각 손실 |
| jewelry | analysis-cma-109609 | hero | 0.9980 (99.8%) | 0.9980 (99.8%) | 1.0000 (100.0%) | OK |
| furniture | analysis-cma-110793 | hero | 0.8855 (88.6%) | 0.8855 (88.6%) | 1.0000 (100.0%) | OK |
```

- **도자기 (`ceramic`, cma-122443)**:
  - 원본 제품의 잉크 면적이 99.9%였으나, Hero 컷아웃에서는 **3.2%만 남고 96.8%가 지워짐** (`보존율: 0.0324`, **심각 손실**).
  - 백자 도자기의 하얀 표면 전체가 투명하게 파여 배경으로 날아가 버림.
- **직물 (`textile`, cma-102980)**:
  - 원본 제품의 잉크 면적이 100.0%였으나, Hero 컷아웃에서 **26.2%만 남음** (`보존율: 0.2624`, **부분 손실**).
  - 직물의 밝은 격자 조직 영역이 배경 판정되어 제품 형상이 훼손됨.
- **나머지 4건 (`box`, `metalware`, `jewelry`, `furniture`)**:
  - 누끼 마스크 실패 시 원본 배경 보존 fallback이 동작하여 100.0% 정상 보존 (**OK**).

### 4.2 결함 원인 분석
- 위치: `src/detail_page_ai/source_photos.py` 내 `SolidBackgroundCutoutExtractor`
- 원인:
  1. 모서리 4개 픽셀의 평균값을 배경색으로 취한 뒤, 전체 픽셀을 순회하며 단순 색거리(Color Distance) 임계값만으로 마스크(알파값)를 결정함.
  2. **외부 배경과의 공간적 연결성(flood-fill, connectivity) 검사가 결여**되어 있어, 배경과 유사한 밝기를 가진 제품 내부 영역(백자 도자기의 몸체, 밝은 직물 무늬)까지 배경으로 판정함.
  3. 밝은 제품이 밝은 단색 배경 위에 놓였을 때 내부가 전부 지워지는 치명적 마스킹 오류 발생.

## 5. 지표 체계의 구멍과 검증 도구 보완

### 5.1 기존 검증 체계의 한계
기존의 자동 파이프라인 검증은 다음 지표들을 사용했습니다:
- React AST 스키마 검증
- 원본 이미지 SHA-256 일치 검증
- 합성 fidelity 검증 (`source_composite` 검증)

그러나 합성 fidelity 검증은 **"선언된 변환(composite)이 전달받은 마스크를 수식 그대로 적용했는가"**만 검증합니다. 따라서 마스크 추출기가 제품 본체를 전부 지워버린 텅 빈 마스크를 반환하더라도, 합성기 자체는 오류 없이 연산을 마쳤으므로 `PASS`로 판정되었습니다. 이로 인해 제품이 97% 지워진 이미지가 버그 없이 자동 게이트를 통과하는 심각한 평가 사각지대가 확인되었습니다.

### 5.2 회귀 판정 도구 신규 구축 (`scripts/check_cutout_fidelity.py`)
이 구멍을 메우기 위해 생성 산출물과 원본의 비배경 픽셀 비율(Ink Ratio)을 계산하여 컷아웃 보존율을 자동 판정하는 스크립트를 새로 제작했습니다.

- **원리**: 256×256 리샘플링 후 Grayscale 밝기 235 미만 픽셀을 잉크로 계측, $\text{보존율} = \frac{\text{산출 잉크 비율}}{\text{원본 잉크 비율}}$.
- **기준**: 0.6 초과 = OK / 0.25 미만 = 심각 손실 / 그 외 = 부분 손실.
- **회귀 게이트**: 심각 손실 발생 시 **종료 코드 1**을 반환하여 배포 파이프라인 및 CI에서 자동 차단.
